## 交互

- 车站和日期复用已有全屏选择器。改变路线、日期、时段或车次类型后清空旧的指定车次，异步查询结果也核验行程，防止串用。
- 席别按点击顺序编号，表示购票优先级。乘车人使用底部选择面板，票种使用下拉菜单。
- 指定车次面板展示车次、出发/到达时间、实际起终站，以及所选席别的成人实时票价；使用查询响应的 `prices_fen`，缺价可调用现有 `query_train_prices` 补查，不估算、不显示零元。
- 保存时检查不同起终站、预售日期、席别、乘车人、有效时间段、3—60 秒查询间隔和正整数重试上限。空名称按行程自动生成。
- 修改未保存时返回会确认；乘车人获取失败可重试或重新登录，重新登录保留草稿。保存任务仍为待运行，用户需要主动启动。
- 列表使用状态页签，更多菜单收纳取消、删除；删除需要确认。只有启动接口成功才启动前台执行服务。
